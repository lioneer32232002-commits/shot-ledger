# SPEC_M19 — 射手檔案的入口動線 ／ 拿掉「→」當 CTA ／ faint 小字收尾（2026-07-30）

三件使用者指出的問題，一起處理。

## 1. 故事頁 CTA 承諾了做不到的事

**問題**：`/stories/` 的主 CTA 原本寫「用這份菜單開始練 →」，連到 `../#/train`。但
挑戰階梯**不給跳關**——讀 Curry（第 16 關）那篇的人，點下去只會落在自己目前的關卡。
文案承諾了一件 App 做不到的事，這是誠實問題，不只是動線問題。

**做法**：不是把限制藏起來，而是把它變成有用的資訊。

- **新增深連結** `#/train?tier=<menuId>`（`app.js parseHash`）。它只是「指路」，不是後門：
  - **已解鎖** → 直接打開那一關的變體面板（可以馬上開打）。
  - **未解鎖** → 停在練球頁，把那張磁磚**標成虛線框**、**橫向捲到畫面中央**，
    並在階梯上方出一張說明卡：這是第幾關、**還差哪一關才會開**、
    「階梯是一關一關走的，你會從目前的進度接著練」。
  - tier 參數用完立刻 `replaceState` 抹掉，重新整理／上一頁不會重複觸發。
- **文案改成做得到的**：主 CTA →「在 App 裡打開第 7 關」，下方補一行
  「挑戰階梯是一關一關解鎖的，打開後會停在你目前的進度。還沒練到這一關也沒關係——
  門檻先當目標。」

**實作要點**
- `session.requestFocusTier(menuId)` 只記下待處理的 id，實際判定在 `mount()`——
  解鎖與否一律讀 `store.isMenuUnlocked()`，外部連結不能繞過（磁磚本身仍是 `disabled`）。
- 磁磚捲動用手算 `scrollLeft`，不用 `scrollIntoView`：後者會連帶把整頁往下捲，
  而 `app.js render()` 剛剛才把頁面捲回頂端。
- 虛線框（`is-focus`）刻意不同於實線 accent 框（`is-current`＝你現在在這關）——
  一個是「你剛在讀這關」，一個是「你在這關」。

## 2. 「→」當 CTA 是最沒有個性的設計語彙

**問題**（使用者指出）：站上很多地方用「→」當行動訊號，很像 AI 樣板。

盤點結果：App 內幾乎沒有——`→` 幾乎只出現在程式註解裡，真正的 UI 只有紀錄頁的返回
「←」（導覽慣例）、出處連結的「↗」（外部連結標準記號）、快速重開的「▶」（圖示）。
**問題全部集中在這次新寫的 `/stories/`**：每頁兩顆 CTA 各帶一個「→」，加上「其他檔案」
每一列右側都有一個「→」。

**做法**
- **CTA 直接拿掉箭頭**。一顆滿版實心按鈕本身就已經是無可誤認的按鈕，箭頭是多餘的裝飾；
  文案改成動詞開頭的具體句子（「在 App 裡打開第 7 關」）比箭頭有用得多。
- **列表列改用「標題底線」**當可點訊號（`text-decoration: underline` ＋
  `border-strong` 色、hover／active 轉 accent）。底線是印刷與網頁一直在用的連結記號，
  跟這幾頁的雜誌調性相符，而且不需要多一個符號欄位。
- 保留的符號：返回「←」（導覽）、出處「↗」（外部連結）、「▶」（快速重開圖示）——
  這三個是既有慣例或圖示，不是 CTA 裝飾。

## 3. faint 小字收尾（承 SPEC_M18 §5，使用者選方向 2「限縮用途」）

`--color-text-faint` 在淺色底只有 3.26〜3.43:1。定案規則寫進 `tokens.css`：

> **faint 只准用在「純裝飾」：圖示、分隔符、虛線框，以及 ≥24px 的大字。
> 凡是承載資訊的文字一律 muted 起跳。**

全站 58 處使用中：**48 處改用 muted**，10 處保留（鎖頭圖示、分隔點、展開標記、
pip 虛線框、「…」省略符號、48px 的 0、locked 徽章的家族小標記、分享卡的＋號）。

順著這次掃描一起修掉的還有三類（都是「accent 當文字」的老問題）：

| 位置 | 修正前 | 修正後 |
|---|---|---|
| 變體面板的出處連結／★ 欄（accent 壓在 sunken 上） | 3.12 | `--color-accent-text` → 5.4 |
| 徽章盤面的門檻數字（18px 粗體） | 2.99 | 同上 |
| 未獲得徽章的門檻數字（原本整塊 faint） | 2.99 | 數字 muted、家族標記維持 faint |
| hero 卡夜幕面板的 accent 數字 | 3.21（改版前就不及格） | `--color-accent-on-night` #FF8A4C → 4.92 |

### 3.1 這一包補完的 token 家族

`--color-accent` 本身**不動**（品牌色）。它在不同用途下的正解不同，各自獨立成 token：

| token | 淺色 | 深色 | 用途 |
|---|---|---|---|
| `--color-fill-accent` | #B8430A | #F2691D | accent **當底色**（按鈕、選中態） |
| `--color-on-fill` | #FFFFFF | #16130F | 壓在飽和色塊**上的文字** |
| `--color-accent-text` | #B8430A | #F2691D | accent **當文字**（淺底要壓深、暗底要提亮，剛好相反） |
| `--color-accent-on-night` | #FF8A4C | #FF8A4C | 夜幕深藍面板上的 accent 文字（面板兩主題都是深藍，不隨主題變） |
| `--color-danger-text` | #B23B2E | #F09A8F | danger 當文字（填色不變） |
